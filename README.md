# Cavaleiro das Trevas

As tochas estam desprendidas da parede e se mexendo, arrume isso, quero que as tochas fiquem presas na parede e imoveis. aliás o bilho delas esta atravessando as paredes arrume isso tambem. o chão está sem textura, deixe o chão com uma textura de chão caverna. o cenario é um labirinto, então o mapa deve ser maior e levar a uma saida apenas, ou seja apenas uma porta de saida, que ficará no final do labirinto em uma parede escura com aluns esqueletos com armadura de guerreiros no chão. deixe o jogo leve para não travar em nenhum momento.
